# Introducción a la ciencia y la técnica

Este repositorio está organizado como una ruta práctica de aprendizaje para la computación científica y técnica. Integra temas fundamentales como control de versiones, scripting en shell, depuración, automatización de compilación, visualización científica, acceso remoto y computación de alto rendimiento.

Este README raíz funciona como un índice exhaustivo de los módulos principales. La carpeta `class-2021` se excluye de este resumen porque contiene trabajos y entregas estudiantiles, no el material central del curso.

## Módulos principales de aprendizaje

1. **Desarrollo con Git y GitHub**
   [developing_with_git](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/developing_with_git)
   
   Presenta conceptos de control de versiones, flujos colaborativos, historial de cambios, ramas, merges y gestión de repositorios remotos con Git y GitHub.

2. **Introducción al scripting en Bash**
   [introduction_to_bash](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_bash)
   
   Explica cómo automatizar tareas en la línea de comandos mediante scripts de Bash, manejo de variables, estructuras de control, argumentos posicionales y flujos de trabajo del shell.

3. **Depuración con gdb**
   [debugging](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/debugging)
   
   Cubre el uso del depurador GNU para inspeccionar el flujo de ejecución, localizar errores lógicos y de tiempo de ejecución, y validar el comportamiento del programa durante el desarrollo.

4. **Makefile, bibliotecas y enlazado**
   [introduction_makefile](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_makefile)
   
   Describe la automatización de compilación con Makefiles, la gestión de dependencias de proyectos, la compilación, las bibliotecas y el enlazado de archivos objeto para producir programas ejecutables.

## Módulos de apoyo científico y técnico

5. **Essentials para entornos científicos**
   [essentials](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/essentials)
   
   Proporciona guías de preparación del sistema para desarrollo de software científico, incluyendo compiladores, instalación de paquetes y configuración del entorno.

6. **Introducción a Gnuplot**
   [introduction_gnuplot](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_gnuplot)
   
   Presenta la generación de gráficos de datos y funciones con Gnuplot, incluyendo visualización científica, gráficos 2D/3D y producción de figuras mediante scripts.

7. **Introducción a MPI**
   [introduction_to_mpi](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_mpi)
   
   Cubre conceptos de computación paralela, configuración tipo clúster y ejecución de cargas de trabajo científicas con MPI y herramientas como Quantum ESPRESSO.

8. **Introducción a SSH**
   [introduction_to_ssh](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_ssh)
   
   Explica la instalación, configuración del acceso remoto, autenticación segura y conexión sin contraseña para sistemas distribuidos y trabajo remoto.

## Resumen de la estructura del repositorio

- [developing_with_git](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/developing_with_git) — conceptos de Git y GitHub, flujo de trabajo básico y ejemplos de comandos.
- [introduction_to_bash](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_bash) — fundamentos del scripting en Bash y ejemplos prácticos.
- [debugging](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/debugging) — recursos de depuración y material orientado a gdb.
- [introduction_makefile](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_makefile) — uso de Makefiles, compilación y ejemplos de programas.
- [essentials](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/essentials) — preparación del entorno y requisitos para software científico.
- [introduction_gnuplot](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_gnuplot) — visualización científica con Gnuplot.
- [introduction_to_mpi](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_mpi) — computación paralela y ejecución distribuida.
- [introduction_to_ssh](https://github.com/Scientific-and-Technical/Scientific_and_Technical/tree/main/introduction_to_ssh) — instalación y configuración de SSH para acceso remoto.

## Propósito del repositorio

El repositorio está pensado para ofrecer una introducción estructurada a las herramientas y prácticas necesarias para el trabajo en software científico y técnico, especialmente en entornos Linux y Unix. Conecta habilidades fundamentales de ingeniería de software con flujos de trabajo aplicados de computación científica.

## Flujo típico de aprendizaje

Una progresión común de estudio es la siguiente:

- preparar el entorno,
- aprender scripting en shell y automatización,
- gestionar el código con Git,
- depurar programas de forma confiable,
- compilar software con Makefiles,
- visualizar resultados con Gnuplot,
- y, cuando sea necesario, escalar cálculos con MPI y acceso remoto mediante SSH.

Por lo tanto, este repositorio se entiende mejor como un conjunto práctico de herramientas para la computación científica y el desarrollo técnico, más que como un único proyecto aislado.
